One-time connection

Use a GitHub fine-grained token with access to the Apextechcr repository and Contents: Read and write permission. The token is used only in this browser tab and is not saved.

Create it in GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Limit it to this repository.
